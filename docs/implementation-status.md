先建立staging资源、Turnstile域和私有R2生命周期；开通必要套餐由运营者自行确认。运行数据库迁移，验证注册/恢复/注销和账户删除，再少量启用HN同步；确认采集公平、队列不积压后，设置低AI预算开启真实分析并抽样验收。最后才公开注册链接。
